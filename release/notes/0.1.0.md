Chrome Stage の最初の公開版です。Google Chrome のプロファイルごとのウィンドウを、一つの作業領域で切り替えられます。

- 手動の Slot 登録と名前付け
- フローティングパレット、メニューバー、グローバルショートカットでの切り替え
- 使用していないウィンドウの画面外退避と、全ウィンドウの復帰
- セッション保存、Chrome 再起動時の再照合、異常終了後の復帰

動作環境: macOS 26 以降、Apple Silicon / Intel Mac、Google Chrome。

ZIP を展開し、`ChromeStage.app` を「アプリケーション」に移動して開いてください。Accessibility の許可が必要です。Dock には表示されないため、メニューバーのアイコンから操作します。画面収録権限は不要です。

詳しくは [インストールと操作方法](https://github.com/shinichinomura/chrome-stage/blob/main/INSTALL.md) と [プライバシー](https://github.com/shinichinomura/chrome-stage/blob/main/PRIVACY.md) を参照してください。

全ウィンドウを戻すには `Control + Option + U`、またはメニューの「Unpark All Chrome Windows」を使います。通常の Chrome ウィンドウを同じ Space 内で使用してください。フルスクリーンや Spaces をまたぐ管理には対応していません。

問題の報告は [GitHub Issues](https://github.com/shinichinomura/chrome-stage/issues) へお願いします。
