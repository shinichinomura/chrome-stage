更新の確認と、自動ダウンロード・インストールに対応しました。

- 起動の少し後と 24 時間ごとに、新しいバージョンがないか GitHub Releases を確認します。新しい版があればダウンロードと検証まで自動で行い、メニューの先頭に「Chrome Stage X.Y.Z に更新して再起動」を表示します。選ぶと、アプリが置き換わって再起動します。
- メニューの「更新を確認…」で、手動でも確認できます。
- 更新は、このアプリと同じ Developer ID 署名・Apple の公証であること、リリースのバージョンと一致すること、実行中より新しいことを確認してから適用します。確認に通らない場合は何も変更しません。
- メニューの「自動で更新を確認」をオフにすると、自動の通信を止められます。通信の内容は [プライバシー](https://github.com/shinichinomura/chrome-stage/blob/main/PRIVACY.md) に記載しています。Slot 名やウィンドウ情報は送信しません。

0.1.1 以前には更新機能がないため、このバージョンへは手動で入れ替えてください。メニューから Chrome Stage を終了し、ダウンロードした `ChromeStage.app` を「アプリケーション」内のものと置き換えます。登録した Slot は保持されます。Accessibility の許可は、再度求められることがあります。以降の更新はメニューから行えます。

自動更新は、アプリの置き換え先に書き込める場合に使えます(通常は「アプリケーション」フォルダ)。

動作環境や操作方法は [インストールと操作方法](https://github.com/shinichinomura/chrome-stage/blob/main/INSTALL.md) を参照してください。問題の報告は [GitHub Issues](https://github.com/shinichinomura/chrome-stage/issues) へお願いします。
